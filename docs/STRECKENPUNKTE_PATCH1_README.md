# Streckenpunkte Patch 1

Enthaltene Änderungen:

- Streckenpunkt **bearbeiten** per Kurzklick
- Streckenpunkt **löschen** per Langklick
- Dialog erweitert um:
  - km-Suffix
  - Typ
  - Objektkennung
  - GPS live anzeigen + **GPS übernehmen**
- Liste zeigt jetzt:
  - km + Suffix
  - Typ
  - Objektkennung
  - GPS ja/nein
- DAO/Repository um **Update** ergänzt

## Einbau

Die Dateien direkt über den vorhandenen Stand aus `tb-Helfer1.6.zip` kopieren.

Ich konnte den Patch hier nicht in einem vollständigen Android-Gradle-Build gegenkompilieren, weil der Upload nur den Quell-/Ressourcenstand enthält. Die Änderungen sind aber als echter Patch mit den geänderten Dateien vorbereitet.
